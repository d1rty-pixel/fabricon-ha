# Bambu Lab R1 (laser cutter, not a 3D printer) - short reference

Research status (2026-11-06): read in the user's Chrome: wiki `/en/r1`, `/en/r1/manual/r1-intro`, `/en/r1/manual/faq`; web
search for the launch. No photos measured. Probably NOT a Bambu / BamBuddy printer for Fabricon (it runs Bambu Suite, not
the print protocol); listed because it is the one other Bambu Lab machine with a laser. Details of the laser itself:
bambu-laser.md section 7.

| Item | Value |
|---|---|
| Name / series | R1 ("R1 Platform", own wiki section; "a new Ray of making") |
| Dates | teaser 2026-08-13, launch and pre-orders 2026-09-22, shipping from about November 2026 |
| Price | 2,499 USD / 2,499 EUR / 2,249 GBP (E1 Pro purifier about 899 USD, riser base, roller feeder 499, rotary 269 USD per press) |
| Type | enclosed desktop laser cutter / engraver, lid on top, no filament |
| Laser | **55 W CO2 glass tube**, 9-11 um, Class 1 standalone, Class 4 with riser base + conveyor; red positioning (650 nm) and blue ranging (450 nm) lasers |
| Work area | 600 x 300 mm, height 0-58 mm (248 mm with riser base), up to 3 m long with roller feeder + rails |
| Speed | 1000 mm/s, 20 000 mm/s2 |
| Weight / noise | about 33.5 kg, 68 dB |
| Power | 780 W max, 100-240 V |
| Structure | Y gantry on rods, X belt axis, Z rack and pinion; mirrors 1-2 on the axes, mirror 3 + lens on the head; air assist nozzle |
| Cooling | liquid coolant circuit (distilled water + antifreeze), radiator + fan, water inlet |
| Safety | PC top lid with Hall sensor, 5 flame sensors, emergency-stop, start / stop button on the upper right, safety key + USB-C on the left panel, optional auto fire extinguisher |
| Cameras | BirdsEye camera + LED in the lid (< 0.6 mm), toolhead close-up camera (< 0.2 mm), LED strips left / right inside |
| Smoke | exhaust fan + port at the back, 2 m hose (86.5 / 75 mm); E1 Pro purifier link via 4-pin |
| Accessories | riser base (taller), roller feeder / conveyor, extension rails (3), rotary attachment (57-105 mm, 500 mm long), vision encoder board, lenses 38.1 (standard) / 50.8 / 63.5 mm, material clamps, slats / base tray |
| Dimensions | not read (picture only); net weight 33.5 kg |

Sources: wiki.bambulab.com/en/r1/manual/faq (official), r1-intro (official), press search results for dates and prices (secondary).
